# Boilerplate

A collection of reusable HTML, CSS and JavaScript tools used during development.

Features
- Theme testing utility
- Screen size tester
- Modal testing page
- Accessibility helpers
- Reusable CSS variables
- Common JavaScript utilities
- Utilities
- Screen Tester

Displays:

- Viewport width
- Viewport height
- Device pixel ratio
- Screen resolution
- Breakpoint information

Useful for validating responsive layouts on real devices.
